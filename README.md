# GMS-Re-Work
A lightweight rework for the Glistering Melon Slice in Minecraft 1.12.2, making it edible and giving powerful status effects.

Features:

• Edible Food

• Regeneration Effect (10s)

• Resistance Effect (10s)


Requirements:

• Forge/Cleanroom for 1.12.2

• For Forge requires the library: MixinBooter. In Cleanroom doesn't need libraries
